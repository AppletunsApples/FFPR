The Fakemon Festival Pack Redux is an ongoing project to share free-to-use Fakemon sprites, PBS data, and cries to the fan game community.

If you would like to contribute, check out the forum post at https://eeveeexpo.com/resources/1871/.

If you notice any errors or stolen art (i.e. art created by you or someone else that is 
not available for public use) please contact us on the above forum immediately.

### RULES ###
To use this resource, you must:
1. Credit the people responsible for using the materials you are using (see Credits.txt)
2. Do not make or collect money on projects that utilize the material in this resource

THANKS! <3
